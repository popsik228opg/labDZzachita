Домашнее задание Бубнов Александр  — Алгоритмы на графах в Java
Группа ПИ 2-1 
Вариант A11 (1вариант)

Реализован алгоритм поиска в ширину (BFS) для ориентированного графа.

Структура проекта

Main.java — запуск программы, создание графа и проверка результатов.

Vertex.java — класс вершины графа.

Edge.java — класс ребра графа.

Graph.java — класс графа и добавление вершин и рёбер.

Bfs.java — реализация алгоритма поиска в ширину.

BfsResult.java — хранение результатов обхода.

Реализованные возможности

Обход графа алгоритмом BFS.

Определение порядка посещения вершин.

Вычисление расстояний от начальной вершины в количестве рёбер.

Восстановление пути до целевой вершины.

Проверка случаев с одной вершиной, недостижимой вершиной, циклом и без цикла.

Проверка повторного запуска алгоритма.

Запуск программы

Необходим установленный JDK.

Из папки src выполнить команды:

javac *.java
java Main

Результат для основного графа

Начальная вершина: A.

Целевая вершина: F.

Порядок посещения: A → B → C → D → E → F.

Найденный путь: A → B → D → F.

Количество рёбер в пути: 3.

Вес рёбер не используется алгоритмом BFS при определении кратчайшего пути. Расстояние измеряется количеством рёбер.
