Студент: Бубнов А.К.
Группа: ПИ 2-1
Вариант: A11
Алгоритм: BFS — поиск в ширину
Среда проверки: OnlineGDB, Java
Задача
Реализован поиск в ширину в ориентированном графе. Программа выводит порядок посещения достижимых из A вершин, расстояния от A в количестве рёбер и путь A→F.
Структура проекта
- src/Main.java — запуск программы и проверки;
- src/Vertex.java — вершина;
- src/Edge.java — ориентированное ребро;
- src/Graph.java — модель графа;
- src/Bfs.java — алгоритм BFS;
- src/BfsResult.java — результаты алгоритма;
- TESTS.md — ожидаемые и фактические результаты проверок;
- Отчет_ДЗ1_A11.docx — отчёт по заданию.
Запуск
Необходим JDK. Из папки src выполнить:
javac *.java
java Main
В OnlineGDB выберите язык Java, добавьте все шесть файлов проекта и нажмите Run.
Основной результат
- Порядок обхода: A -> B -> C -> D -> E -> F
- Расстояния: A=0, B=1, C=1, D=2, E=2, F=3
- Путь: A -> B -> D -> F
- Количество рёбер: 3
BFS минимизирует количество рёбер, а не сумму весов. Поэтому веса рёбер не используются при выборе пути.
